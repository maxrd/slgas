## 三、驗證碼 (CAPTCHA) 深入分析

### 3.1 取得驗證碼

```
GET https://www.shinhaigas.com.tw/API/shgasweb/VertifyCode
```

**回應範例 (JSON)**：

```json
{
  "Img": "data:image/gif;base64,R0lGODlh...",
  "Hash": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJjYXB0Y2hhIiwianRpIjoiSE1CQyIsImV4cCI6MTc4MTUxODE3MywiaXNzIjoiU2hpbkhhaUdBUyIsImF1ZCI6ImViaWxsIn0.xxx"
}
```

| 欄位 | 說明 |
|------|------|
| `Img` | GIF 圖片 base64 Data URL (`data:image/gif;base64,...`) |
| `Hash` | HS256 JWT，有效期 **約 5 分鐘** |

### 3.2 驗證碼圖片特徵

- **格式**: GIF（非 SVG，雖 HTML src 預設是 .svg 但 API 回傳 GIF）
- **尺寸**: 70 x 22 px (顯示為 125x50)
- **大小**: ~1.4 – 1.9 KB (base64 約 1900 chars)
- **內容**: 4 個大寫英數字元，深藍底白字，略帶雜訊線條
- **範例**: `HMBC`、`F6K2`、`CDX4`、`N4YM`、`TTCR`

### 3.3 ⚠️ 重大安全發現：JWT 洩漏答案

**JWT Payload 解碼** (base64 decode，無需密鑰):

```json
{
  "sub": "captcha",
  "jti": "HMBC",          ← 驗證碼答案直接在這裡！
  "exp": 1781518173,
  "iss": "ShinHaiGAS",
  "aud": "ebill"
}
```

**結論**: `jti` 欄位即為驗證碼正確答案。JWT payload 採用 base64url 編碼（非加密），可直接解碼取得。

**這意味著**：
- 不需要任何 OCR 或 Google AI 解析圖片
- 只需解碼 JWT payload 即可得到答案
- 原本設計的圖形防護完全無效

### 3.4 驗證碼驗證流程

```
POST https://www.shinhaigas.com.tw/API/shgasweb/Vertify
Content-Type: application/json

{
  "Captcha": "HMBC",      ← 用戶輸入的答案（或從 JWT jti 解碼）
  "Hash": "<JWT token>"   ← GET VertifyCode 取得的 Hash
}
```

**回應**:
- `HTTP 200` + 空 body → 驗證成功
- `HTTP 401` → 驗證碼錯誤
- `HTTP 400` → 驗證碼過期（超過 ~5 分鐘）
- `HTTP 500` → 系統錯誤

## 五、Session / Cookie 行為

### 5.1 Cookie 觀察

| Cookie | 值 | HttpOnly | Secure |
|--------|----|----------|--------|
| `AspxAutoDetectCookieSupport` | `1` | `False` | `False` |

**重要發現**：
- 首頁訪問 **不設定** 任何 Session Cookie
- 驗證碼取得後 **不設定** Session Cookie
- 驗證碼驗證後只有 `AspxAutoDetectCookieSupport=1`（IIS 標準 cookie）
- **無傳統 server-side session**：驗證狀態完全依賴 JWT (Hash) 傳遞

### 5.2 無狀態設計

```
瀏覽器           →  GET /VertifyCode    →  伺服器產生 JWT (含答案於 jti)
                 ←  { Img, Hash }       ←
瀏覽器 (驗證)    →  POST /Vertify       →  伺服器驗證 JWT 簽章 + 比對答案
                 ←  200 OK              ←
瀏覽器 (查詢)    →  POST /Data          →  直接查詢，不依賴 session
                 ←  user data          ←
```

**結論**：每次 API 呼叫彼此獨立，不需要維護 Cookie Session。

## 七、實作方案

### 7.1 Reporter 實作步驟

```python
# reporters/shinhai.py 實作流程

async def submit(degree: str, ...) -> bool:
    async with aiohttp.ClientSession() as session:
        # Step 1: GET /API/shgasweb/VertifyCode
        r = await session.get(CAPTCHA_URL)
        data = await r.json()
        hash_jwt = data['Hash']
        
        # Step 2: 解碼 JWT payload (不需密鑰)
        payload = decode_jwt_payload(hash_jwt)
        captcha_answer = payload['jti']          # 直接取答案
        
        # Step 3: POST /API/shgasweb/Vertify
        await session.post(VERIFY_URL, json={
            'Captcha': captcha_answer,
            'Hash': hash_jwt
        })
        
        # Step 4: POST /API/shgasweb/Data (查詢)
        r = await session.post(DATA_URL, json={
            'FUNNAME': 'WebQueryHouseNo',
            'FUN_CODE': 'Q001',
            'BODY': {'QUERY_TYPE': '1', 'QUERY_USER_NO': user_no}
        })
        query_data = await r.json()
        address_pure = query_data['DOCDATA']['BODY']['QUERY_DATA1']
        
        # Step 5: POST /API/shgasweb/Data (寫入度數)
        await session.post(DATA_URL, json={
            'FUNNAME': 'WebWriteToDegreeNew',
            'FUN_CODE': 'I002',
            'BODY': {
                'DEGREE_USER_NO': user_no,
                'DEGREE_ADDRESS': address_pure,
                'DEGREE_TEL': tel,
                'DEGREE_MOBILE': mobile,
                'DEGREE_NUMBER': degree,
                'DEGREE_QUERY_COUNT': 3
            }
        })
```

### 7.3 Google AI 圖形解析

雖然可直接從 JWT 取得驗證碼答案，但若未來伺服器修正此漏洞，Google AI 解析方案如下：

```python
import google.generativeai as genai

async def solve_captcha_with_ai(img_base64: str) -> str:
    """使用 Google AI 解析 GIF 驗證碼"""
    model = genai.GenerativeModel('gemini-2.0-flash')
    
    image_part = {
        'inline_data': {
            'mime_type': 'image/gif',
            'data': img_base64
        }
    }
    
    response = model.generate_content([
        image_part,
        "這是一個驗證碼圖片，請只回傳圖中的4個字元（大寫英文字母和數字），不要有其他文字。"
    ])
    
    return response.text.strip().upper()
```
