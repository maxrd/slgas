## 1. Home Assistant 水表 Sensor 配置

### 1.1 設備類型與單位

**HA 官方規範：**

```python
# 水表 sensor 應使用以下配置
from homeassistant.components.sensor import SensorDeviceClass, SensorStateClass
from homeassistant.const import UnitOfVolume

class WaterMeterSensor(SensorEntity, RestoreEntity):
    """水表度數 Sensor (能源面板支援)"""
    
    _attr_device_class = SensorDeviceClass.WATER          # ✅ 識別為水表
    _attr_state_class = SensorStateClass.TOTAL_INCREASING # ✅ 單調遞增值
    _attr_native_unit_of_measurement = UnitOfVolume.CUBIC_METERS  # m³
    # 或 UnitOfVolume.LITERS (L)，根據台水的度數單位決定
```

### 1.2 能源面板支援條件

- ✅ `device_class = WATER`
- ✅ `state_class = TOTAL_INCREASING`
- ✅ `native_unit_of_measurement` = m³ 或 L
- ✅ 使用 RestoreEntity 恢復上次狀態
- ✅ 值必須為數字（不帶單位字串）

**差異對比：**
| 項目 | 瓦斯 (GAS) | 水 (WATER) |
|------|-----------|----------|
| device_class | SensorDeviceClass.GAS | SensorDeviceClass.WATER |
| state_class | TOTAL_INCREASING | TOTAL_INCREASING |
| 單位 | m³ | m³ 或 L |
| HA 能源面板顯示 | ✅ 支援 | ✅ 支援 |
| 圖示 | 瓦斯桶 | 水滴 |

```python
# custom_components/slgas/sensor.py 新增水表類別

class WaterMeterSensor(SensorEntity, RestoreEntity):
    """水表度數 Sensor (支援能源面板)"""

    def __init__(self, report_service, entry, meter_type="water"):
        self._report_service = report_service
        self._entry = entry
        self._meter_type = meter_type  # "gas" 或 "water"
        
        water_no = entry.data.get("water_no", "")
        self._attr_name = f"水表度數 ({water_no})"
        self._attr_unique_id = f"{entry.entry_id}_water_meter"
        self._attr_icon = "mdi:water"
        
        # 關鍵：正確設定 device_class 和 state_class
        self._attr_device_class = SensorDeviceClass.WATER
        self._attr_state_class = SensorStateClass.TOTAL_INCREASING
        self._attr_native_unit_of_measurement = UnitOfVolume.CUBIC_METERS
        self._attr_native_value = None

    async def async_added_to_hass(self):
        """啟動時恢復上次狀態"""
        await super().async_added_to_hass()
        last_state = await self.async_get_last_state()
        if last_state and last_state.state not in ("unknown", "unavailable", None):
            try:
                self._attr_native_value = int(last_state.state)
                _LOGGER.info(f"已恢復水表度數: {last_state.state}")
            except (ValueError, TypeError):
                _LOGGER.warning(f"無法恢復水表狀態: {last_state.state}")

    def update_meter(self, degree: int):
        """由 report_service 呼叫更新度數"""
        self._attr_native_value = degree
        self.async_write_ha_state()
```

## 2. 台灣自來水 POST 上報流程分析

### 2.1 申請頁面信息

**申請 URL**: `https://www.water.gov.tw/ch/ECounter/Apply`

**必需參數:**
- NodeId=752
- type=17 (代表自報類型)
- UseCertificate=0

### 2.2 表單欄位映射

| 台水網站欄位 | HTML Input Name | 中文說明 | 資料型態 | 必填 |
|------------|-----------------|---------|--------|------|
| 申請人姓名 | 待確認* | Applicant Name | string | ✅ |
| 聯繫電話 | 待確認* | Phone/Mobile | string | ✅ |
| 電子郵件 | 待確認* | Email | string | ✅ |
| 水號 | 待確認* | Water Account (XXX-XXX) | string | ✅ |
| 用水地址 | 待確認* | Service Address | string | ✅ |
| 指針數（度數） | 待確認* | Meter Reading | integer | ✅ |
| 指針照片 | 待確認* | Photo File | file (JPEG/PNG, max 4MB) | ✅ |
| 圖形驗證碼 | 待確認* | CAPTCHA Code | string | ✅ |
| 合同同意1 | 待確認* | 營業規則 | checkbox | ✅ |
| 合同同意2 | 待確認* | 個資通知 | checkbox | ✅ |
| 合同同意3 | 待確認* | 消費者用水服務條約 | checkbox | ✅ |

*實際欄位名稱需透過瀏覽器開發者工具檢查，或使用 Selenium/Playwright 抓取 form HTML

### 2.3 預期 POST 流程

**方案 A：單步驟 POST (如欣隆)**
```
POST /ch/ECounter/Apply (或類似端點)
Content-Type: multipart/form-data

Fields:
- applicant_name: "張三"
- phone: "0912345678"
- email: "example@gmail.com"
- water_no: "123-456"
- meter_reading: "1234"
- photo: [binary image data]
- captcha_code: "XXXXX"  ← 需要使用者手動輸入或 UI 交互
- agree_1: "1"
- agree_2: "1"
- agree_3: "1"
```

**方案 B：多步驟 POST (可能模仿欣隆的兩步驟驗證)**
```
Step 1: POST 驗證身份資訊
  → Response: 返回驗證碼圖片或隱藏欄位

Step 2: POST 提交完整資訊 + 驗證碼
  → Response: 成功訊息 ("自報水表指數已登錄完成" 之類)
```

### 2.4 驗證碼處理策略

```python
# custom_components/slgas/report_service.py

class ReporterServiceBase:
    """基底服務，支援多公司多類型"""
    
    @property
    def image_path(self) -> str:
        """根據 meter_type 和識別號生成圖片路徑"""
        meter_type = self.config.get(CONF_METER_TYPE, "gas")  # "gas" 或 "water"
        company = self.config.get(CONF_COMPANY, "slgas")      # "slgas", "water_taipei" 等
        
        if meter_type == "gas":
            cus_no = self.config.get(CONF_CUS_NO, self.entry.entry_id[:8])
            filename = f"slgas_gas_{company}_{cus_no}.png"
        elif meter_type == "water":
            water_no = self.config.get(CONF_WATER_NO, self.entry.entry_id[:8])
            water_no_clean = water_no.replace("-", "")  # 移除格式符號
            filename = f"slgas_water_{water_no_clean}.png"
        else:
            filename = f"slgas_{company}_{self.entry.entry_id[:8]}.png"
        
        return f"{DEFAULT_IMAGE_DIR}/{filename}"

    @property
    def image_filename(self) -> str:
        """只返回檔名，用於 AI task 的 media_content_id"""
        import os
        return os.path.basename(self.image_path)
```

```python
# custom_components/slgas/reporters/base.py

from abc import ABC, abstractmethod
from typing import Dict, Any

class BaseReporter(ABC):
    """所有上報模組的標準接口"""
    
    def __init__(self, hass, config: Dict[str, Any]):
        self.hass = hass
        self.config = config
        self.last_status = "未初始化"
    
    @abstractmethod
    async def submit(self, degree: str, image_path: str = None) -> bool:
        """上報度數到遠端伺服器
        
        Args:
            degree: 度數 (字串格式)
            image_path: 可選的圖片路徑
        
        Returns:
            bool: 成功為 True，失敗為 False
        """
        pass
    
    def validate_config(self) -> bool:
        """驗證配置的完整性"""
        raise NotImplementedError
    
    def get_required_fields(self) -> list:
        """回傳此模組需要的設定欄位清單"""
        raise NotImplementedError
```

### 5.2 Config Flow 代碼框架

```python
# custom_components/slgas/config_flow.py

import voluptuous as vol
from homeassistant import config_entries
from homeassistant.data_entry_flow import FlowResult
from typing import Any, Dict

class SlgasConfigFlow(config_entries.ConfigFlow, domain=DOMAIN):
    """SLGAS 整合的設定流"""
    
    VERSION = 1
    
    async def async_step_user(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """初始化步驟"""
        if user_input is not None:
            return await self.async_step_meter_type()
        
        return self.async_show_form(
            step_id="user",
            data_schema=vol.Schema({}),
            description_placeholders={
                "help_text": "點下一步開始設定"
            }
        )
    
    async def async_step_meter_type(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 1: 選擇類型 (瓦斯/水)"""
        if user_input is not None:
            self.meter_type = user_input.get("meter_type")
            return await self.async_step_company()
        
        return self.async_show_form(
            step_id="meter_type",
            data_schema=vol.Schema({
                vol.Required("meter_type"): vol.In({
                    "gas": "瓦斯",
                    "water": "水錶"
                })
            })
        )
    
    async def async_step_company(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 2: 選擇公司 (動態過濾)"""
        if user_input is not None:
            self.company = user_input.get("company")
            return await self.async_step_basic_info()
        
        # 根據 meter_type 過濾公司選項
        if self.meter_type == "gas":
            companies = {
                "slgas": "欣隆天然瓦斯",
                "taipeigas": "大台北瓦斯"
            }
        else:  # water
            companies = {
                "water_taipei": "台灣自來水"
            }
        
        return self.async_show_form(
            step_id="company",
            data_schema=vol.Schema({
                vol.Required("company"): vol.In(companies)
            })
        )
    
    async def async_step_basic_info(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 3: 基本資訊 (動態欄位)"""
        if user_input is not None:
            self.basic_info = user_input
            return await self.async_step_ocr_config()
        
        # 根據公司動態生成欄位
        schema_dict = {}
        
        if self.company == "slgas":
            schema_dict = {
                vol.Required("cus_no"): str,
                vol.Required("cus_name"): str,
                vol.Required("cus_phone"): str,
            }
        elif self.company == "water_taipei":
            schema_dict = {
                vol.Required("applicant_name"): str,
                vol.Required("water_no"): vol.All(str, vol.Match(r"^\d{1,3}-\d{1,3}$")),
                vol.Required("phone"): str,
                vol.Required("email"): str,
            }
        
        return self.async_show_form(
            step_id="basic_info",
            data_schema=vol.Schema(schema_dict)
        )
    
    async def async_step_ocr_config(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 4: OCR 設定"""
        if user_input is not None:
            self.ocr_config = user_input
            # 若為水錶且需要驗證碼，進入驗證碼步驟
            if self.meter_type == "water" and self.company == "water_taipei":
                return await self.async_step_captcha()
            else:
                return await self.async_step_advanced()
        
        # 根據 meter_type 推薦 prompt
        if self.meter_type == "water":
            default_prompt = "這是一張水錶的照片，請提取黑色數字部分的整數度數，忽略紅色小數部分。"
        else:
            default_prompt = DEFAULT_PROMPT  # 既有瓦斯 prompt
        
        return self.async_show_form(
            step_id="ocr_config",
            data_schema=vol.Schema({
                vol.Required("camera_entity"): cv.entity_id,
                vol.Required("ocr_source", default=OCR_SOURCE_GOOGLE_AI): vol.In({
                    OCR_SOURCE_GOOGLE_AI: "Google AI (需連網)",
                    OCR_SOURCE_EXTERNAL: "外部實體"
                }),
                vol.Optional("prompt", default=default_prompt): str,
                vol.Optional("degree_entity", default=""): cv.entity_id,
            })
        )
    
    async def async_step_captcha(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 5: 驗證碼 (僅水錶)"""
        if user_input is not None:
            self.captcha_code = user_input.get("captcha_code")
            return await self.async_step_advanced()
        
        # ⚠️ 實現方案：使用 Playwright 取得驗證碼圖片
        # 這需要前端支援顯示圖片和輸入框
        
        return self.async_show_form(
            step_id="captcha",
            data_schema=vol.Schema({
                vol.Required("captcha_code"): str,
            }),
            description_placeholders={
                "captcha_image_url": "https://placeholder/captcha.png",  # 實際 URL
                "help_text": "請輸入上方圖片中的驗證碼"
            }
        )
    
    async def async_step_advanced(self, user_input: Dict[str, Any] = None) -> FlowResult:
        """步驟 6: 進階選項"""
        if user_input is not None:
            # 整合所有資訊，建立 ConfigEntry
            config_data = {
                "meter_type": self.meter_type,
                "company": self.company,
                **self.basic_info,
                **self.ocr_config,
                **(self.captcha_code and {"captcha_code": self.captcha_code} or {})
            }
            
            # 合併進階選項
            config_data.update(user_input)
            
            return self.async_create_entry(
                title=f"[{self.meter_type}] {self.company}",
                data=config_data
            )
        
        return self.async_show_form(
            step_id="advanced",
            data_schema=vol.Schema({
                vol.Optional("notify_script", default=""): cv.entity_id,
                vol.Optional("text_entity", default=""): cv.entity_id,
                vol.Optional("schedule_time", default="08:00"): cv.time,
                vol.Optional("history_days", default=30): cv.positive_int,
            })
        )
```

```python
# custom_components/slgas/reporters/water_taipei.py

import logging
import aiohttp
from bs4 import BeautifulSoup
from .base import BaseReporter

_LOGGER = logging.getLogger(__name__)

class WaterTaipeiReporter(BaseReporter):
    """台灣自來水公司 (Taiwan Water Corporation) 上報模組"""
    
    BASE_URL = "https://www.water.gov.tw/ch/ECounter"
    APPLY_URL = f"{BASE_URL}/Apply?NodeId=752&type=17&UseCertificate=0"
    
    def __init__(self, hass, config: dict):
        super().__init__(hass, config)
        self.applicant_name = config.get("applicant_name", "")
        self.water_no = config.get("water_no", "")
        self.phone = config.get("phone", "")
        self.email = config.get("email", "")
        self.image_path = config.get("image_path", "")
    
    def validate_config(self) -> bool:
        """驗證必要設定"""
        required = ["applicant_name", "water_no", "phone", "email"]
        return all(self.config.get(key) for key in required)
    
    def get_required_fields(self) -> list:
        """回傳台水需要的欄位"""
        return ["applicant_name", "water_no", "phone", "email", "camera_entity"]
    
    async def submit(self, degree: str, image_path: str = None) -> bool:
        """上報水表度數到台灣自來水
        
        ⚠️ 注意：因為台水系統有圖形驗證碼，無法完全自動化
           本方法應在 config_flow 已取得驗證碼後才呼叫
        """
        if not image_path:
            image_path = self.image_path
        
        _LOGGER.info(f"[台水] 準備上報度數: {degree}, 圖片: {image_path}")
        
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
        }
        
        try:
            # 讀取圖片二進制資料
            with open(image_path, 'rb') as f:
                image_data = f.read()
            
            # 準備 multipart/form-data
            async with aiohttp.ClientSession(headers=headers) as session:
                
                # 建立 FormData
                data = aiohttp.FormData()
                
                # 基本資訊欄位 (字段名稱根據實際台水表單調整)
                data.add_field('applicant_name', self.applicant_name)
                data.add_field('water_no', self.water_no)
                data.add_field('phone', self.phone)
                data.add_field('email', self.email)
                data.add_field('meter_reading', degree)
                
                # 上傳圖片 (字段名稱根據實際台水表單調整)
                import os
                filename = os.path.basename(image_path)
                data.add_field(
                    'meter_photo',  # ← 根據台水實際欄位名調整
                    open(image_path, 'rb'),
                    filename=filename,
                    content_type='image/png'
                )
                
                # 驗證碼 (若已在 config_flow 取得)
                if hasattr(self, 'captcha_code'):
                    data.add_field('captcha_code', self.captcha_code)
                
                # 合同同意
                data.add_field('agree_rules', '1')
                data.add_field('agree_privacy', '1')
                data.add_field('agree_terms', '1')
                
                # 提交 POST
                async with session.post(self.APPLY_URL, data=data) as response:
                    if response.status != 200:
                        _LOGGER.error(f"[台水] POST 失敗，狀態碼: {response.status}")
                        self.last_status = f"POST 失敗: {response.status}"
                        return False
                    
                    html_response = await response.text(encoding='utf-8', errors='ignore')
                    
                    # 判斷成功訊息
                    success_keywords = ["自報水表指數已登錄完成", "成功", "已登錄"]
                    if any(keyword in html_response for keyword in success_keywords):
                        _LOGGER.info("[台水] 水表度數上報成功！")
                        self.last_status = f"上報成功: {degree}"
                        return True
                    else:
                        _LOGGER.warning(f"[台水] 未找到成功訊息，回傳內容片段: {html_response[:200]}")
                        self.last_status = "上報失敗: 未得到確認訊息"
                        return False
        
        except FileNotFoundError:
            _LOGGER.error(f"[台水] 找不到圖片: {image_path}")
            self.last_status = f"錯誤: 找不到圖片"
            return False
        
        except Exception as e:
            _LOGGER.error(f"[台水] 上報時出錯: {e}")
            self.last_status = f"錯誤: {str(e)}"
            return False
```
