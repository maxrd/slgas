## 快速開始

### 安裝步驟

1. **安裝整合**
   - 打開 HACS → Integrations
   - 搜尋 `slgas`
   - 點擊安裝

2. **重啟 Home Assistant**
   ```
   設定 → 系統 → 重新啟動
   ```

3. **建立整合**
   ```
   設定 → 裝置與服務 → 建立自動化
   → 搜尋 "通用能源自動回報"
   ```

4. **跟隨設定流程**
   6 個簡單步驟，完成配置

## 瓦斯配置詳解

### 第 1 步：選擇類型

**選擇**: ⛽ **瓦斯**

```
開啟配置 → 第一頁會看到兩個選項
┌─────────────────┐
│ ⛽ 瓦斯          │ ← 選這個
├─────────────────┤
│ 💧 水錶         │
└─────────────────┘
```

### 第 2 步：選擇公司

**選擇**: **欣隆天然瓦斯**

```
系統會自動過濾，瓦斯類型下只會顯示：
┌──────────────────────┐
│ 欣隆天然瓦斯         │ ← 選這個
└──────────────────────┘
```

### 第 3 步：填入客戶資訊

需要填入以下資訊（請查看欣隆瓦斯帳單或合約）：

| 欄位 | 說明 | 例子 |
|------|------|------|
| **客戶號** | 欣隆瓦斯給您的客戶編號 | `012345` |
| **客戶名稱** | 開單時的姓名 | `王小明` |
| **聯繫電話** | 任何聯繫方式 | `0912345678` |

**去哪裡找這些資訊？**
- 欣隆瓦斯帳單
- 合約書
- 欣隆瓦斯官網帳戶頁面

### 第 4 步：選擇度數來源

#### 🎥 Google AI 模式（推薦）

```
度數來源: Google AI (攝影機 + AI 辨識)
```

**需求**:
- ✅ 對準瓦斯表的攝影機（已接入 HA）
- ✅ Google Generative AI 整合（已設定）
- ✅ 足夠照明（日光或補光燈）

**優點**:
- 完全自動，無需人工
- 拍照 + 自動識別 + 自動上報

**缺點**:
- 需要好的攝影機和光線

#### 📝 外部實體模式

```
度數來源: 外部實體 (input_text / sensor)
```

**適用於**:
- 已有其他 OCR 工具取得度數
- 手動輸入度數到 input_text

**優點**:
- 靈活，可整合其他系統

**缺點**:
- 需先有度數來源

### 第 5 步：設定 OCR（根據選擇）

#### 如果選 Google AI

1. **攝影機**: 選擇對準瓦斯表的攝影機
   ```
   例: IP Cam 瓦斯表、USB 攝影機 等
   ```

2. **提示詞**: 系統已有預設，可保持預設或自訂
   ```
   預設: "這是一張瓦斯表的照片,請提取左邊黑底白色..."
   ```

#### 如果選外部實體

1. **度數實體**: 選擇提供度數的 input_text 或 sensor
   ```
   例: input_text.gas_meter_reading
   ```

### 第 6 步：進階選項

1. **度數存放實體** ✅ 必填
   - 辨識結果會存到這裡
   - 創建一個新的 `input_text`
   - 例: `input_text.gas_degree_confirmed`

2. **排程時間** ✅ 必填
   - 每天自動拍照和辨識的時間
   - 例: `08:00` (早上 8 點)
   - ⚠️ 不會自動上報，只是辨識

3. **通知腳本** 選填
   - 回報完成後執行
   - 例: 發送推播通知、Telegram 訊息
   - 跳過這項也可以

4. **歷史天數** 選填
   - 保留多少天的回報紀錄
   - 預設: 90 天
   - 範圍: 1～365 天

### 配置完成 ✅

系統會建立以下實體：
- 🔢 瓦斯度數 (sensor)
- 📋 回報狀態 (sensor)
- ⚡ 確認並上報按鈕
- 📸 分析度數按鈕

## 日常使用

### 自動辨識流程

系統會在設定的時間自動執行：

```
每日 08:00
    ↓
📷 拍照
    ↓
🤖 AI 辨識
    ↓
📊 更新度數感測器
    ↓
✅ 完成
```

> ⚠️ **注意**: 自動辨識**不會**自動上報網站，只是更新本地度數。

### 手動確認和上報

1. **檢查辨識結果**
   ```
   設定 → 裝置與服務 → 實體
   → 搜尋 "度數存放"
   → 查看目前數值
   ```

2. **確認無誤後點擊按鈕**
   ```
   設定 → 裝置與服務 → 實體
   → 搜尋 "確認並立即上報"
   → 點擊按鈕
   ```

3. **等待回報完成**
   ```
   監控 "回報狀態" 感測器
   看到 "上報成功: XXXX" 表示成功
   ```

### 查看歷史紀錄

在 HA 儀表板新增卡片：

```yaml
type: markdown
content: |
  | 時間 | 度數 | 狀態 |
  |------|------|------|
  {% for r in state_attr('sensor.gas_report_status_12345', 'history') %}
  | {{ r.date }} | {{ r.degree }} | {{ r.status }} |
  {% endfor %}
```

## 故障排除

### ❌ 辨識結果不準確

**症狀**: AI 識別的度數明顯錯誤

**解決方案**:
1. 檢查攝影機清晰度
   - 確保鏡頭清潔
   - 調整焦距
   
2. 改善光線
   - 白天在窗邊
   - 晚上加補光燈（紅外或 LED）
   
3. 調整提示詞
   - 進階使用：修改 config → 編輯整合 → 更改 Prompt
   - 針對表盤類型優化

### ❌ 上報失敗

**症狀**: 看到「上報失敗」

#### 瓦斯（欣隆）
- 檢查客戶號、名稱是否與帳單一致
- 查看欣隆網站是否可以手動申報
- 嘗試改天再上報

#### 水錶（台灣自來水）
- 確認水號格式正確（`123-456`）
- 確認申請人名稱完全一致
- 檢查網站是否在維護

### ❌ 按鈕不出現

**症狀**: 看不到「確認並上報」按鈕

**檢查清單**:
- [ ] 整合是否已完全載入（重啟 HA）
- [ ] 度數存放實體是否填寫正確
- [ ] 攝影機是否已正確選擇（Google AI 模式）

### ❌ 度數感測器一直是「0」

**症狀**: 感測器數值未更新

**解決方案**:
1. 查看排程時間是否已過
2. 檢查回報狀態感測器是否有錯誤訊息
3. 尋找日誌中的錯誤

## 進階配置

### 多帳戶配置

可以在同一個整合下管理多個帳戶：

```
設定 → 裝置與服務
→ 已安裝 → 通用能源自動回報
→ 建立新的配置條目
→ 輸入第二個帳戶資訊
```

每個帳戶會有獨立的：
- 感測器
- 按鈕
- 排程

**例子**:
```
帳戶 1: 家裡瓦斯 (CusNo: 111111)
帳戶 2: 租屋處瓦斯 (CusNo: 222222)
帳戶 3: 家裡水錶 (Water No: 123-456)
```

### 能源面板整合

#### 添加瓦斯消耗

1. 前往 **設定 → 儀表板 → 能源**
2. 在「瓦斯消耗」點擊「新增瓦斯來源」
3. 選擇對應的感測器（例: `sensor.gas_meter_111111`）
4. （可選）輸入瓦斯單價

#### 添加水消耗

1. 前往 **設定 → 儀表板 → 能源**
2. 在「水消耗」點擊「新增水來源」
3. 選擇對應的感測器（例: `sensor.water_meter_123456`）
4. （可選）輸入水價

### 自定通知腳本

#### 推播通知範例

```yaml
script:
  gas_notify:
    alias: 瓦斯回報通知
    sequence:
      - service: notify.mobile_app_iphone
        data:
          title: "🔥 瓦斯度數回報"
          message: "{{ message }}"
          data:
            image: "{{ data.file }}"
            actions:
              - action: "URI"
                title: "查看詳情"
                uri: "https://my.home-assistant.io/..."
```

#### Telegram 通知範例

```yaml
script:
  gas_notify_telegram:
    alias: 瓦斯 Telegram 通知
    sequence:
      - service: notify.telegram
        data:
          title: "⛽ 瓦斯度數"
          message: "{{ message }}"
          data:
            photo:
              - "file:{{ data.file }}"
```

## 常見問答

**Q: 可以完全自動上報嗎？**
A: 目前不行。系統會自動辨識度數，但上報需手動確認（點按鈕）。這是為了安全，避免誤報。

**Q: 度數存放實體一定要建立嗎？**
A: 是的。這個實體用於存放辨識結果，供確認和上報使用。

**Q: 如果攝影機夜間無光怎麼辦？**
A: 加裝紅外補光燈。Google AI 可以識別紅外影像。

**Q: 可以修改排程時間嗎？**
A: 可以。進入整合設定，編輯並修改排程時間。

**Q: 舊度數會保留嗎？**
A: 度數感測器會自動恢復上次值。歷史紀錄在設定的天數內保留。
